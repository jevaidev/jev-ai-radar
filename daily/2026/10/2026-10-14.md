- The ranking now contains **86 Jev-related GitHub projects**, up from 77 in the October 9 website snapshot.

  - [`RayenMlayeh/jevcrawl`](https://github.com/RayenMlayeh/jevcrawl), an MCP server and CLI that uses Jev to select links and passages while crawling a site.

  - [`mdmintz/jev-testing`](https://github.com/mdmintz/jev-testing), a SeleniumBase example that asks Jev whether a CAPTCHA is present and which type it is.
  - [`jmagly/aiwg`](https://github.com/jmagly/aiwg), a multi-provider workflow toolkit with an optional Jev decision-support addon.
  - [`Dicklesworthstone/skillranker`](https://github.com/Dicklesworthstone/skillranker), a Rust CLI that uses Jev-compatible providers to rank agent skills against live session context.

## System One ecosystem

The maintained collection now covers **33 independent models and interfaces**, up from 29 in the previous maintained website snapshot. Four projects joined the collection:

- [`Laya Decision Engine`](https://github.com/NandhaKishorM/laya), multilingual Laya decision checkpoints and training resources.
- [`VegaML`](https://github.com/NandhaKishorM/vegaml), Qwen3.5-based decision models in 0.8B and 4B sizes.
- [`laya-java`](https://github.com/apscot/laya-java), a Java interface for Laya models through ONNX Runtime.
- [`train-jev`](https://github.com/shibing624/train-jev), training recipes for Jev-style models based on Qwen3.5-4B and Qwen3.8-27B.

The System One collection is maintained rather than append-only. These projects are independent community work and are not official TypeSafe Jev releases.
