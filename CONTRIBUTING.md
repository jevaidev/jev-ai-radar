# Contributing to Jev AI Radar

Contributions are welcome for:

- Jev integrations, SDKs, tools, applications, and examples.
- Open models or interfaces clearly related to System One-style typed decisions.
- Public demonstrations that show a concrete Jev decision inside a product or workflow.
- Corrections to descriptions, metadata, licenses, or project status.

## Submit an item

Open a submission issue and include:

1. A public source URL.
2. A concise description of what is demonstrated.
3. The decision being made, such as Choice, Score, or Noul.
4. The relationship to Jev or the wider System One ecosystem.
5. Any limitations or claims that need independent verification.

## Editorial rules

- Official TypeSafe resources and independent community work must be labelled separately.
- Creator-reported speed, cost, or accuracy figures are described as claims rather than independent benchmarks.
- Summaries must be original and link to the source.
- A repository must contain relevant public code or documentation.
- Promotional submissions without clear technical or editorial value may be declined.
- Security, quality, and maintenance are not implied by inclusion.

## Corrections

Open an issue with the affected item, the corrected information, and a supporting source. Maintainers may edit wording so descriptions stay concise and consistent.
